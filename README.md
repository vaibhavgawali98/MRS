# 🎬 ReelVerse AI

ReelVerse AI is a Netflix-style movie recommendation web app built using Machine Learning and Streamlit.  
The app recommends movies similar to the one selected by the user using cosine similarity and vectorization techniques.

It also provides:
- movie posters
- trailers
- ratings
- genres
- release dates
- movie overviews

through the TMDB API.

# 🧠 Machine Learning Used

This project uses Content-Based Filtering for movie recommendations.

### Techniques used:
- Text Vectorization
- Cosine Similarity
- Feature Engineering
- Data Preprocessing

The recommendation system suggests movies based on similarity between movie metadata such as:
- genres
- keywords
- cast
- crew
- overview
